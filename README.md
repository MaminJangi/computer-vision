## Assignments

| Assignment | Work included | Reports |

## Get started

See [CA1/README.md](CA1/README.md) for installation, execution, input files, generated videos, and submission notes. Each notebook combines executable code with its report; the HTML versions are self-contained exports for browser viewing after download.

Input images, the source video, assignment PDF, generated images, and all three output videos are included. The repository therefore contains large media files. Jupyter checkpoints and local environment/cache files are excluded.
